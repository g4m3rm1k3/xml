## What You'll Learn

### Database Concepts
- Tables, primary keys, foreign keys
- Normalization vs denormalization
- Unique constraints
- Transactions
- JOIN queries (LEFT, INNER)
- Aggregation (COUNT, GROUP BY)
- Composite keys

### Python Concepts
- Functions and parameters
- Default parameters
- Type conversion (int, float)
- String manipulation
- Regular expressions
- List comprehensions
- Dictionary grouping
- f-strings and formatting
- Error handling (try/except)
- Helper functions

### Web Development
- Flask routes
- URL parameters
- GET vs POST
- Form handling
- Templates (Jinja)
- Flash messages
- Redirects

### XML Parsing
- ElementTree
- find() vs findall()
- Nested elements
- Defensive parsing
- Text extraction

### Software Engineering
- **Vertical slicing** - build end-to-end
- **Dependency order** - build from bottom up
- **SOLID principles** - single responsibility, dependency injection
- **DRY** - Don't Repeat Yourself
- **YAGNI** - You Ain't Gonna Need It
- **Repository Pattern** - Abstraction for data access
- **Dependency Inversion** - Depend on abstractions, not concretions
- **Design patterns** - Strategy, Get-or-Create, Drill-down
- **Defensive programming** - check for None, validate input
- **Idempotency** - safe to run multiple times
- **Polymorphism** - different inputs, same output
- **Progressive enhancement** - graceful degradation

## Teaching Style

Every iteration follows the same pattern:

1. **Question before answer** - make you think
2. **Tradeoff discussion** - show multiple options
3. **Every line explained** - tables showing what and why
4. **Engineering concepts** - general principles, not just code
5. **Test each step** - prove it works
6. **Summary** - what you learned

**No code dumps. No lazy teaching. Deep understanding.**
