# Mastercam PDM Tutorial Series

Welcome to your software engineering apprenticeship. You'll learn by **building a real application**.

## The Goal

Build a system that:

- Parses Mastercam XML reports
- Validates data quality (errors & warnings)
- Stores historical data for analysis
- Generates custom reports via templates

## How to Use These Tutorials

1. **Read the tutorial** on this site
2. **Type the code yourself** (no copy-paste!)
3. **Run it** and see what happens
4. **Understand** before moving on

!!! tip "The Rule"
    Never move to the next step until you can explain what the current code does.
