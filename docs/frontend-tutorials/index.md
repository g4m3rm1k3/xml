## Quick Rules of Thumb

### The 5 Design Principles (From Tutorial 01)

1. **Hierarchy** — Most important thing should be biggest/boldest
2. **Whitespace** — When in doubt, add more space
3. **Alignment** — Everything should align to something
4. **Contrast** — Text must be readable (4.5:1 ratio minimum)
5. **Proximity** — Related things should be close together

### The Color Rule (From Tutorial 02)

**60-30-10 Rule:**
- 60% — Primary color (background)
- 30% — Secondary color (cards, containers)
- 10% — Accent color (buttons, links)

### The Typography Rule (From Tutorial 03)

**Use 2 fonts max:**
- 1 for headings (can be decorative)
- 1 for body text (must be readable)

### The Layout Rule (From Tutorials 05-06)

**Flexbox vs Grid:**
- **Flexbox** → One-dimensional (row OR column)
- **Grid** → Two-dimensional (rows AND columns)
